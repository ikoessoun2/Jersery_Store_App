
The project is meant to be able to extend *on Github* or used *when hosted*.

### **On Github**

1. **Locally Installing the project**
    - Clone or download the repository from [ikoessoun2's Jersey Store App](https://github.com/ikoessoun2/Jersery_Store_App).
    - There are two directories within the project directory; *Frontend* and *Backend*. 
    - Within *Frontend* use `npm i` to install all dependencies.
    - Within *Backend* 
        - Create a virtual environment with `python -m venv .venv`.
        - Activate the virtual environment with `.venv\Scripts\Activate.ps1`.
        - Use `pip install -r requirements.txt` to install all dependencies in the virtual environment. 

    1. The frontend is meant to be built into the static/dist directory of the /backend. This is to ensure that the backend can call the frontend directly.
